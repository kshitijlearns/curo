# Fixtures

The deterministic demo dataset the mock providers serve (built in Phase 2).

- `generate.py` — regenerates everything from a fixed seed.
- `data/` — the generated dataset: the demo creator, 10 peers, reels with growth
  curves, comments, T1 video outputs, hashtag pages, the festival calendar and
  sample videos for the Simulator.

No real Instagram data is ever stored here.
